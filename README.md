# Skill Bridge – Frontend

A frontend web application designed to connect learners with skill-based opportunities and resources.

## Features

- User-friendly frontend interface
- Responsive web design
- Skill-based learning and opportunity platform
- Clean and simple navigation

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

The project contains the frontend components and resources required to build the Skill Bridge web application.

## Live Demo

https://earnest-medovik-b549d1.netlify.app

## Purpose

The purpose of Skill Bridge is to provide a platform where users can explore skills, learning resources, and career-related opportunities.
